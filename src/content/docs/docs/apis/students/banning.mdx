**Endpoint Overview**

Ban a student record from your organization by providing either `studentId` or `userId`.

* **HTTP Method:** `POST`
* **Endpoint URL:** `https://api.trywhiteowl.com/api/v1/students/ban`
* **Authentication:** Bearer Token (API Key)
* **Required Permission:** `students:ban` (Ensure your API key has **Ban** permission under **Students**)

---

### Request Headers

| Header | Type | Required | Description |
| --- | --- | --- | --- |
| `Authorization` | String | Yes | Bearer token format: `Bearer YOUR_API_KEY` |
| `Content-Type` | String | Yes | `application/json` |

---

### Request Body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `studentId` | Number | Conditional | Numeric database ID of the student. Required if `userId` is omitted. |
| `userId` | String | Conditional | Auth user string ID of the student. Required if `studentId` is omitted. |

**Example Payload:**

```json
{
  "studentId": 2
}

```

---

### Code Examples

**cURL**

```bash
curl -X POST "https://api.trywhiteowl.com/api/v1/students/ban" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "studentId": 2
  }'

```

**JavaScript (Fetch)**

```javascript
const options = {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    studentId: 2
  })
};

fetch('https://api.trywhiteowl.com/api/v1/students/ban', options)
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(err => console.error(err));

```

**Python (Requests)**

```python
import requests

url = "https://api.trywhiteowl.com/api/v1/students/ban"
headers = {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
}
payload = {"studentId": 2}

response = requests.post(url, headers=headers, json=payload)
print(response.json())

```

---

### Response Structure

**Success Response (`200 OK`)**

```json
{
  "success": true,
  "message": "Student successfully banned",
  "data": [
    {
      "id": 2,
      "name": "Alex Smith",
      "email": "alex.smith@example.com",
      "baned": true,
      "organization": "org_12345"
    }
  ]
}

```

**Error Responses**

* **Missing Identifier:**
```json
{
  "success": false,
  "message": "You have to either provide studentId or userID to ban the student"
}

```


* **Student Not Found:**
```json
{
  "success": false,
  "message": "This student probably does not exist in your organization"
}

```


* **Missing Permissions (`403 Forbidden`):**
```json
{
  "success": false,
  "message": "Your API key does not have the 'students:ban' permission"
}

```
