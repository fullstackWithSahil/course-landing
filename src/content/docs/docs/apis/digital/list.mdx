**Endpoint Overview**

Retrieve a list of all digital products under your organization.

* **HTTP Method:** `GET`
* **Endpoint URL:** `https://api.trywhiteowl.com/api/v1/digital`
* **Authentication:** Bearer Token (API Key)
* **Required Permission:** `digital:read` (Ensure your API key has **Read** permission under **Digital**)

---

### Request Headers

| Header | Type | Required | Description |
| --- | --- | --- | --- |
| `Authorization` | String | Yes | Bearer token format: `Bearer YOUR_API_KEY` |
| `Content-Type` | String | Yes | `application/json` |

---

### Code Examples

**cURL**

```bash
curl -X GET "https://api.trywhiteowl.com/api/v1/digital" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json"

```

**JavaScript (Fetch)**

```javascript
const options = {
  method: 'GET',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  }
};

fetch('https://api.trywhiteowl.com/api/v1/digital', options)
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(err => console.error(err));

```

**Python (Requests)**

```python
import requests

url = "https://api.trywhiteowl.com/api/v1/digital"
headers = {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
}

response = requests.get(url, headers=headers)
print(response.json())

```

---

### Response Structure

**Success Response (`200 OK`)**

```json
{
  "success": true,
  "message": "Digital products fetched successfully",
  "data": [
    {
      "id": "dig_98765",
      "organization": "org_12345",
      "type": "digital",
      "name": "E-Book: Mastery in TypeScript",
      "price": 29.99,
      "created_at": "2026-09-01T12:00:00Z"
    }
  ]
}

```

**Error Responses**

* **Missing Permissions (`403 Forbidden`):**
```json
{
  "success": false,
  "message": "Your API key does not have the 'digital:read' permission"
}

```


* **Internal / Database Error (`500 Internal Server Error`):**
```json
{
  "success": false,
  "message": "There was an error getting the digital products"
}

```
