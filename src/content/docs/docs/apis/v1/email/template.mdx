**Endpoint Overview**

Fetch a list of all email templates created for your organization.

* **HTTP Method:** `GET`
* **Endpoint URL:** `https://api.trywhiteowl.com/api/v1/email`
* **Authentication:** Bearer Token (API Key)
* **Required Permission:** `email:read` (Ensure your API key has **Read** permission under **Email**)

---

### Request Headers

| Header | Type | Required | Description |
| --- | --- | --- | --- |
| `Authorization` | String | Yes | Bearer token format: `Bearer YOUR_API_KEY` |
| `Content-Type` | String | Yes | `application/json` |

---

### Code Examples

**cURL**

```bash
curl -X GET "https://api.trywhiteowl.com/api/v1/email" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json"

```

**JavaScript (Fetch)**

```javascript
const options = {
  method: 'GET',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  }
};

fetch('https://api.trywhiteowl.com/api/v1/email', options)
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(err => console.error(err));

```

**Python (Requests)**

```python
import requests

url = "https://api.trywhiteowl.com/api/v1/email"
headers = {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
}

response = requests.get(url, headers=headers)
print(response.json())

```

---

### Response Structure

**Success Response (`200 OK`)**

```json
{
  "success": true,
  "message": "Email templates fetched successfully",
  "data": [
    {
      "id": "tmpl_101",
      "name": "Welcome Email",
      "subject": "Welcome to WhiteOwl!",
      "body": "<h1>Welcome aboard!</h1>",
      "organization": "org_12345",
      "created_at": "2026-04-10T14:20:00Z"
    }
  ]
}

```

**Error Responses**

* **Missing Permissions (`403 Forbidden`):**
```json
{
  "success": false,
  "message": "Your API key does not have the 'email:read' permission"
}

```


* **Internal / Database Error (`500 Internal Server Error`):**
```json
{
  "success": false,
  "message": "There was an error getting email templates"
}

```
